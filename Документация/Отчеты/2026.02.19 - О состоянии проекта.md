## 1. Общее описание проекта

**Цель НИР:** адаптация открытого RISC-V ядра Core-V Wally (5-ступенчатый конвейерный процессор, RV32I) для FPGA-платы Terasic DE2-115 (Intel Cyclone IV E, EP4CE115F29C7). Работа включает:

- Замену Xilinx-специфичных IP-ядер на аналоги Intel
- Адаптацию системы сборки под Quartus Prime
- Разработку моста AHB-Lite <-> Avalon для интерфейсов системных шин
- Создание блоков on-chip памяти (RAM/ROM) для кэша
- Разработку загрузчика (ZSBL) и SDK для пользовательских программ

## 4. Архитектура проекта

### 4.1 Структура каталогов (не удачный вариант)

```
intel-cvw/
├── src/               # RTL-исходники ядра Wally (адаптированные под Intel)
│   ├── config/        #   Конфигурация процессора (RV32IMF_Zicsr)
│   ├── cache/         #   Подсистема кэша
│   ├── ebu/           #   External Bus Unit (AHB)
│   ├── fpu/           #   Блок плавающей запятой
│   ├── ieu/           #   Целочисленный исполнительный блок
│   ├── ifu/           #   Блок выборки инструкций + предсказатель переходов
│   ├── lsu/           #   Блок загрузки/хранения
│   ├── mdu/           #   Умножитель/делитель
│   ├── mmu/           #   Блок управления памятью + TLB
│   ├── privileged/    #   Привилегированный режим, CSR
│   ├── uncore/        #   Периферия: UART, GPIO, SPI, CLINT, PLIC
│   └── generic/mem/   #   Обобщённые модули памяти (RAM/ROM)
├── ip_cores/          # Intel-специфичные IP-ядра
│   ├── qsys/src/      #   AHB-to-Avalon мост, SDRAM контроллер
│   ├── ram1p1rwbe/    #   Однопортовая RAM с побайтовой записью
│   ├── ram2p1r1wbe/   #   Двухпортовая RAM (1R+1W)
│   └── rom1p1r_/      #   Однопортовая ROM
├── fpga/src/          # FPGA-уровень: top-модуль, testbench, SRAM модель
├── scripts/           # TCL-скрипты сборки (Quartus, Qsys, Questa, System Console)
├── sdk/               # SDK для пользовательских программ (C/asm)
├── zsbl/              # Zero Stage Boot Loader
├── docker/            # Docker-образ с RISC-V тулчейном
└── constraints/       # Файл ограничений для DE2-115
```

### 4.3 Процесс сборки и использование различных инструментов спомощью make

```
make docker_setup        → Docker-образ с RISC-V GCC
make zsbl_build          → Загрузчик (boot.mif)
make qsys_generate       → Генерация Qsys-системы (Platform Designer)
make quartus_create      → Создание проекта Quartus
make quartus_build       → Синтез и сборка FPGA-прошивки
make qsim_create/open    → Симуляция в QuestaSim
```

## 8. Текущее состояние и открытые вопросы

### Что реализовано (done)

- Портирование ~246 SystemVerilog-файлов ядра Wally под Intel Quartus
- 3 типа IP-ядер памяти (Intel MegaFunction)
- Мост AHB-Lite <-> Avalon (отлажен)
- SDRAM-контроллер 128 MB
- SRAM-контроллер 2 MB
- Полная build-система (Makefile + Quartus + Qsys + QuestaSim + Docker)
- Загрузчик ZSBL с передачей управления в SRAM
- SDK с библиотеками периферии и примерами

### Что в работе (in progress)

- Расширение SDK: добавлен пример CLINT-таймера с прерываниями
- Стабилизация синтеза после включения FPU (серия fix-коммитов 15—16.02)
- Пометки `TODO` в коде по связыванию адресации из `config.vh` с остальными компонентами

### Потенциальные риски

- **Адресная консистентность.** Коммит `429a777` явно отмечает необходимость синхронизации адресов между `config.vh` и остальными файлами — это технический долг.
- **Отсутствие автоматических тестов.** Нет CI/CD, нет regression-тестов для RTL; верификация выполняется вручную.
