# Запуск Операционных систем на разработанной компьютерной системе
## Актуальное направление развития проекта адаптации RISC-V ядра Wally

---

## 1. Текущее состояние проекта

### Что уже реализовано

✅ **Базовая компьютерная система**
- RISC-V процессорное ядро Core-V Wally (5-ступенчатый конвейер)
- Конфигурация: **RV32IMF_Zicsr**
  - **I** — базовый набор целочисленных инструкций
  - **M** — аппаратное умножение/деление
  - **F** — операции с плавающей точкой
  - **Zicsr** — работа с CSR-регистрами

✅ **Инфраструктура**
- Мост AHB-Lite ↔ Avalon
- IP-ядра памяти (RAM/ROM) для Intel FPGA
- SDRAM контроллер (128 MB)
- SRAM контроллер (2 MB)

✅ **Программная экосистема**
- Zero Stage Boot Loader (ZSBL)
- SDK с библиотеками периферии
- Docker-окружение с RISC-V GCC toolchain

## 3. Технические требования для запуска ОС

### 3.1 FreeRTOS — требования

| Компонент | Минимум | Рекомендуется | Текущее состояние |
|-----------|---------|---------------|-------------------|
| **ISA** | RV32I | RV32IM | ✅ **RV32IMF** |
| **RAM** | 16 KB | 64 KB | ✅ **2 MB SRAM + 128 MB SDRAM** |
| **Прерывания** | Machine-mode | Machine + Timer | ⚠️ **Частично (CLINT реализован)** |
| **CSR** | Базовые | Полный набор | ✅ **Zicsr** |
| **Периферия** | UART | UART + Timer | ✅ **UART, GPIO, CLINT** |

**Вывод:** FreeRTOS можно запустить **уже сейчас** с минимальными доработками.

### 3.2 Linux — требования

| Компонент | Минимум | Рекомендуется | Текущее состояние |
|-----------|---------|---------------|-------------------|
| **ISA** | RV32IMA | RV32GC (RV32IMAFD_Zicsr_Zifencei) | ⚠️ **RV32IMF** (нет атомарных операций) |
| **Privilege Modes** | M + S + U | M + S + U + H | ⚠️ **Требует проверки** |
| **MMU** | Sv32 | Sv32 | ⚠️ **Модуль mmu/ есть, нужна верификация** |
| **RAM** | 32 MB | 128 MB+ | ✅ **130 MB total** |
| **Interrupts** | PLIC/CLINT | PLIC + CLINT | ⚠️ **CLINT работает, PLIC требует проверки** |
| **Storage** | RAM disk | SD/MMC/SPI | ⚠️ **SDC/SPI в адресной карте, требует драйверов** |

**Вывод:** Linux требует **существенных доработок**, но архитектурно система готова.

## 4. Gap Analysis: Что нужно доработать

### 4.1 Для FreeRTOS (ближайшая цель)

```
Готовность: ████████░░ 80%
```

**Необходимые доработки:**

1. **Настройка портов FreeRTOS**
   - Адаптация `port.c` для RV32IMF
   - Конфигурация `FreeRTOSConfig.h` под текущую систему

2. **Проверка системы прерываний**
   - Верификация CLINT (Machine Timer Interrupt)
   - Тестирование обработчиков исключений

3. **Оптимизация памяти**
   - Настройка heap для FreeRTOS (в SRAM)
   - Конфигурация стека задач

**Срок:** 2-4 недели

---

### 4.2 Для Linux (средне-долгосрочная цель)

```
Готовность: ████░░░░░░ 40%
```

**Критичные доработки:**

1. ⚠️ **Расширение ISA до RV32IMA**
   - Добавление атомарных операций (A-extension)
   - Проверка конфигурации ядра Wally

2. ⚠️ **Верификация MMU (Sv32)**
   - Проверка модуля `mmu/` на совместимость с Linux
   - Тестирование TLB и трансляции адресов

3. ⚠️ **Полная система прерываний**
   - Верификация PLIC (Platform-Level Interrupt Controller)
   - Поддержка режимов M/S/U privileges

4. 🔧 **Хранилище данных**
   - Драйвер SD-карты через SPI
   - Rootfs на RAM disk (initramfs)

5. 🔧 **Bootloader**
   - Расширение ZSBL для загрузки Linux
   - Реализация OpenSBI (Supervisor Binary Interface)

**Срок:** 3-6 месяцев
