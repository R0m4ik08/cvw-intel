## Текущее состояние

### Что есть сейчас

Конфигурация компьютерной системы осуществляется через разные источники:

* Параметры процессорной системы Wally: `src/config/config.vh`
* Параметры компьютерной системы для платы DE2-115: Проект в Platform Designer:
  * Набор компонентов:
    * Базовые: PLL, Кнтролер сброса, ПС Wally, `AHB`->`Avalon` мост, контроллеры памяти (SRAM, SDRAM);
    * Опциональные: `JTAG` to `FPGA` мост, `HEX` индикаторы;
    * Опциональные (не реализованы): `USB`,`PS/2`  контроллеры, `RS232`,`IrDA` - `UART`, 16x2 `LCD` символьный дисплей и т.п.
  * Адресное пространство
* Глобальные выводы модуля верхнего уровня: Quartus проект и FpgaTop.sv
* Параметры SDK:
  * Скрипт линкера: zsbl и прикладное ПО
  * Конфигурация архитектуры Risc-V для компилятора
  * Аппаратно зависимые файлы программ: описание системы `system.h`, драйвера (gpio, uart, clint и др.)


### Ограничения текущей реализации

❌ **Ручное редактирование** - все изменения вносятся вручную в 
❌ **Нет валидации** - легко создать несовместимую конфигурацию  
❌ **Нет документации** - неясно какие комбинации параметров допустимы  
❌ **Сложность синхронизации** - изменения нужно вносить в несколько мест  
❌ **Нет версионирования** - сложно отследить изменения конфигурации  
❌ **Нет шаблонов** - каждый раз настройка с нуля

## Проблема

Текущий подход к конфигурации создает следующие проблемы:

### 1. Высокий риск ошибок

**Пример несовместимых конфигураций:**
- Включен Compressed (C), но не включен Zca (обязательная зависимость)
- Включен Floating Point (F), но FLEN < XLEN
- Адреса периферии пересекаются
- Размер кэша не является степенью двойки

### 2. Сложность для новых пользователей

Для создания новой конфигурации нужно:
1. Понять огромный пласт параметров
2. Изучить зависимости между ними
3. Прочитать спецификацию RISC-V
4. Вручную проверить совместимость
5. Обновить несколько файлов (config.vh, SDK, ZSBL)

### 3. Отсутствие повторного использования

Нет библиотеки готовых конфигураций:
- Минимальная система (RV32I)
- Встраиваемая система (RV32IMC)
- Система с FPU (RV32IMFD)
- Полная система (RV32GC)
- Система для Linux (RV64IMAFDC_Zicsr_Zifencei)

### 4. Сложность тестирования

Невозможно автоматически протестировать все комбинации параметров:
- Ручное создание каждой конфигурации
- Нет CI/CD для проверки конфигураций
- Сложно воспроизвести ошибки
